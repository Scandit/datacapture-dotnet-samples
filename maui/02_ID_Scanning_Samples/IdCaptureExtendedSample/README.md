# Id Capture Extended Sample

This sample demonstrates the ID Capture API with support for extended document types including passports, driver's licenses, and national ID cards with VIZ, barcode, and MRZ scanning modes.

## Installation

- Clone this repo locally.
- Sign in to your Developer Account at [ssl.scandit.com](http://ssl.scandit.com) and generate a license key. If you do not have an account, sign up here: [https://ssl.scandit.com/dashboard/sign-up?p=test](https://ssl.scandit.com/dashboard/sign-up?p=test).
- Open the solution in Visual Studio.
- Set the license key in the application configuration (refer to the sample's code comments for the exact location).
- Build and run this sample on your target device or emulator.

## What is ID Capture?

ID Capture is a capability of Scandit's Data Capture SDK that enables fast and accurate scanning of identity documents including passports, driver's licenses, and national ID cards.
